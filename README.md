# Hi, I'm Ash 👋

I'm a **Technical UX Designer for Learning** at [Qt Group](https://www.qt.io/) in Finland, sitting in the overlap between **technical writing, instructional design, UX, and graphics programming**. I make the kind of learning content I always wished existed when I was teaching myself shaders at 2am.

My background is unusual on purpose: I've taught game development at degree level, shipped 3D and shader work as a Technical Artist for synthetic-data simulations, and now design and build the courses, prototypes, and code examples that help developers get productive with Qt.

---

## 🛠 What I'm working on

- **Qt Academy** — designing and producing courses, code challenges, and video content for QML and Qt developers. Lots of work on scalable content pipelines, transcript tooling, and template systems behind the scenes.
- **Curriculum & UX prototyping** — Figma-first design for new product experiences and learning journeys.
